# Engineering apps

These are .NET file-based apps. Run each with `dotnet run eng/<app>.cs -- <arguments>`.

- `regress.cs` runs the ported pglogical regression suite with `ankus regress` on a fresh development cluster, using the settings from pglogical's `regress-postgresql.conf`. Pass `--pg <major>`, and optionally `--repeat <count>`, `--huge-tx` to add the three `huge_tx` tests, `--no-build` to test the extension `ankus build` last published, and a test name filter.
- `stress.cs` runs the suite repeatedly to catch flaky tests, as pglogical's `scripts/stress-tests.sh` does. Pass `--pg <major>`, and optionally `--runs <count>` (default 10), `--stop-on-fail` and `--huge-tx`. Failed runs keep their diffs, results and server log under `artifacts/stress/run-N`.
- `package.cs` packages worf for one PostgreSQL major version on the current platform: the extension from `ankus package` and `worf_create_subscriber`, laid out as `bin/`, `lib/` and `share/extension/`, in a tar.gz on Linux and macOS, or a zip and an MSI (with WiX 5) on Windows. First it installs the package into a copy of the PostgreSQL installation it was built for, whose server must load the extension and report the package's version. Pass `--pg <major>` and `--version <version>`, and optionally `--output <directory>` (default `artifacts/packages`).
- `codeql.cs` fails when the CodeQL workflow found anything, listing each result in the SARIF files under the directory it is given that no `// codeql[rule] reason` comment suppresses. With `drop-generated` it first removes the results under `obj/`, where source generators write code worf does not own.
- `share.cs` prints the MSTest filter for the multi-server tests one CI job runs. A platform's five jobs, one per PostgreSQL major version, split the tests into shares balanced by `test-times.txt`, each test's seconds on a macOS job, and the workflow run's number rotates which version takes which share, so every test runs on each platform in every run and on every version over five runs. Tests in the `EveryVersion` category run in every job. Pass `--pg <major>`, `--platform <rid>` and `--run <number>`.
